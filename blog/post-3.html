JavaScript Fundamentals: Variables, Functions & Logic

Introduction: Why You Need to Master This

JavaScript is where the magic happens. It turns a static webpage into an interactive experience. But most beginners get stuck because they try to learn React before they truly understand JS. I did the same. Let's go back to the basics and build a rock-solid foundation.

The Core Concept (Explained Simply)

Variables store data. Functions perform actions. Logic (if/else) makes decisions. These three concepts are the building blocks of every app you've ever used.

Real Code: Copy, Paste, and Run

// Variables let userName = "DigiSone"; const pi = 3.14; // Function function greetUser(name) { return "Hello, " + name + "!"; } // Logic if (userName === "DigiSone") { console.log(greetUser("Admin")); } else { console.log("Unknown User"); }

Step-by-Step Execution

Follow these steps exactly:

  1. Step 1: Open your browser and press F12 to open Developer Tools.
  2. Step 2: Click on the 'Console' tab.
  3. Step 3: Type `let x = 5;` and press Enter.
  4. Step 4: Type `x * 2` and press Enter. See the output?
  5. Step 5: Paste the code above into the console and hit Enter. Watch the magic happen.
