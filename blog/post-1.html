What is HTML5, Really?

HTML stands for HyperText Markup Language. It is not a programming language; it is a markup language. This is a crucial distinction. You don't write logic or loops in HTML. Instead, you wrap content in tags that tell the browser what that content is. Is it a heading? A paragraph? An image? A navigation link?

HTML5 is the fifth and current major version of HTML. It introduced a set of semantic tags that changed the game. Before HTML5, developers used generic `

Real Code: A Complete HTML5 Document

Let's build a full page from scratch. Copy this code into a file named `index.html` and open it in your browser.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Semantic Page</title>
    <meta name="description" content="A complete HTML5 page built from scratch.">
</head>
<body>
    <header>
        <h1>Welcome to My Site</h1>
        <nav>
            <ul>
                <li><a href="#about">About</a></li>
                <li><a href="#services">Services</a></li>
                <li><a href="#contact">Contact</a></li>
            </ul>
        </nav>
    </header>
    <main>
        <section id="about">
            <h2>About Us</h2>
            <p>We are a team of developers passionate about the web.</p>
        </section>
        <section id="services">
            <h2>Our Services</h2>
            <article>
                <h3>Web Development</h3>
                <p>We build fast, accessible websites.</p>
            </article>
        </section>
    </main>
    <aside>
        <h3>Quick Links</h3>
        <ul>
            <li><a href="#">Blog</a></li>
            <li><a href="#">Careers</a></li>
        </ul>
    </aside>
    <footer>
        <p>&copy; 2024 My Site. All rights reserved.</p>
    </footer>
</body>
</html>
